# Florencio Store

Esta é uma loja de comunidade para o Umbrel.

## Como instalar no seu Umbrel

1. Acesse a App Store no seu Umbrel.
2. Clique em "Community Stores" ou no ícone de configurações.
3. Adicione a URL deste repositório: `https://github.com/seu-usuario/florencio_store` (Substitua pela URL real após o upload).

## Aplicativos Disponíveis

- **Agent DVR**: Plataforma avançada de vigilância por vídeo.
